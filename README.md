#### 🔷 how i build

I like owning the whole stack frontend, backend, infra, deployment. I build backends from scratch instead of reaching for a BaaS, because understanding how the pieces actually fit together is half the point. Most of what's above started as a freelance brief, a hackathon idea, or a problem I ran into myself, and I'd rather ship something rough that solves it than polish something that never ships.
